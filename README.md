## 📅 Dashboard Calendar

A sleek and minimal **Dashboard Calendar Web App** built with **HTML, CSS, and JavaScript**. This project allows users to view a dynamic calendar interface that can be used as a base for scheduling dashboards, task planners, or time management tools.

🔗 [Live Demo](https://dashboardcalender.netlify.app)

---

### 🚀 Features

- 📆 Interactive and responsive calendar UI  
- 🗓️ Highlights current date  
- 🔄 Month navigation with dynamic date rendering  
- 🌗 Light & clean dashboard-style design  
- 📱 Mobile-friendly layout

---

### 🛠️ Tech Stack

- **HTML5** – Semantic structure  
- **CSS3** – Custom styling with responsiveness  
- **JavaScript (Vanilla)** – Dynamic date calculations and DOM interaction

---

### 📂 Project Structure

```
├── index.html     # Main HTML structure
├── style.css      # Custom styles for calendar and layout
└── script.js      # JavaScript logic for calendar interactivity
```

### 🧪 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/dashboard-calendar.git
   cd dashboard-calendar
   ```

2. Open `index.html` in your browser.
